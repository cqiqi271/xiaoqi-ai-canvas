# Quick Start for Friends

1. Unzip `Infinite-Canvas-ultralite.zip` anywhere on Windows.
2. Double-click `run.bat`.
3. The app will print the exact port it picked and open the browser.

If it does not start:
- Make sure the `python/` folder is still next to `run.bat`.
- Check the `run.log` file for the exact error.
- If you want online AI features, configure API keys in `API/.env`.

This is a self-contained local package. No GitHub is required.
